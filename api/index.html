    standardize()

    Center/scale each response and its exog, rescale load to average-day units.

    Each response metric's values and exog columns are z-scored (center/scale stored in scaling for back-transform); load is rescaled by its own mean so gains stay \(O(1)\).

    Returns:

    Type Description
    Panel

    A new standardized panel.

    birm.model

    The impulse-response model specification.

    IRModel dataclass

    Declarative spec of the shared-stock multivariate impulse-response model.

    Selects one impulse-response core \(R_t\) via fitness \(\times\) fatigue and attaches one observation layer per Metric. Call fit with a Panel to sample.

    Parameters:

    Name Type Description Default
    load Load

    The training-load driver \(w_t\).

    		 required
    fitness str

    Fitness core \(M_F\); one of banister, ceddia_periodize, ceddia_taper, ceddia.

    		 required
    fatigue str

    Fatigue core; one of banister, busso, none.

    		 required
    metrics tuple[Metric, ...]

    Response metrics sharing the single latent stock.

    		 required
    priors dict[str, Prior]

    Optional overrides for named model parameters (e.g. k_p, k_a, tau_v).

    		 dict()
    parameterization str

    Latent-stock prior geometry; one of informed, admissible, or direct. informed (default) samples the identifiable reparameterized margins (\(\theta, \lambda_F, \lambda_G\)) so the gain ratio and timescale ordering \(\tau_v < \tau_G < \tau_F\) and \(k_G > k_F\) hold with certainty (off the \(\tau_F = \tau_G\) ridge). admissible is identical but floors the gain ratio at the Ceddia (2026) admissibility metric \(a_c\) via \(k_G = (a_c + \theta) k_F\), so \(P(k_G/k_F > a_c) = 1\) in the posterior. direct instead samples \(k_F\), \(k_G\), \(\tau_F\), \(\tau_G\) (and Busso \(\tau_v\)) independently from weakly-informative HalfNormal/LogNormal priors over wide ranges, with no ordering or gain-ratio constraint -- the ill-conditioned baseline the reparameterization is designed to fix.

    		 'informed'

    build_model(panel)

    Parameters:

    Name Type Description Default
    panel Panel

    Observations to bind, with metric names matching this spec's Metric names.

    		 required

    Returns:

    Type Description

    The assembled model, ready to sample.

    fit(panel, sampler=None)

    Validate this spec against panel, build the model, and sample the posterior.

    Checks that every spec metric exists in the panel with resolvable exog columns, warns on unused panel metrics, assembles the PyMC model via build_model, then samples.

    Parameters:

    Name Type Description Default
    panel Panel

    Observations to fit, with metric names matching this spec's Metric names.

    		 required
    sampler dict[str, Any]

    Overrides merged over the R&D defaults (_SAMPLER_DEFAULTS: nutpie NUTS, draws=1000, tune=2500, chains=4, target_accept=0.99), passed through to pymc.sample.

    		 None

    Returns:

    Type Description
    Any

    An arviz.InferenceData with the posterior and per-metric obs_<name> likelihoods.

    Raises:

    Type Description
    ValueError

    If a spec metric is missing from the panel, or references an exog column that metric does not carry.

    Metric dataclass

    One response series \(Y^{(j)}\) as a noisy readout of the shared stock.

    Parameters:

    Name Type Description Default
    name str

    Metric name; must match a key in Panel.metrics.

    		 required
    link str

    Link function \(l^{(j)}\); one of identity, log, logit.

    		 'identity'
    exog tuple[str, ...]

    Exogenous predictor columns \(X^{(j)}\) (-> \beta), read off this metric's rows.

    		 ()
    ar1 bool

    Whether to include the orthogonalized lag-1 process \(u^{(j)}\).

    		 False
    intercept bool

    Whether to include the intercept \(\alpha^{(j)}\).

    		 True
    gamma float

    Fixed scale \(\gamma^{(j)}\). If None the densest metric is auto-pinned to \(\gamma \equiv 1\) and the rest are estimated.

    		 None
    offset bool

    Whether to read this metric's stock at a shifted time \(r_{t-d}\) with an integer lag \(d\) (support \(\{0,\dots,14\}\) if causal, else \([-14,14]\)) under a 0-centered discrete Gaussian prior, marginalized out via logsumexp. The shift applies to the stock term only; any ar1 residual and exogenous terms stay contemporaneous.

    		 False
